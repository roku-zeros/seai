## SEAI-only

Для любого вопроса или задачи о коде в этом workspace автоматически используй SEAI. Пользователю не нужно писать «через SEAI» или вызывать skill вручную. Это постоянный порядок работы, а не опциональный приём поиска.

Если доступны MCP-инструменты `seai_connect` / `seai_read`, начинай с `seai_connect`, сверяй project root и используй MCP вместо shell. `seai_read` фиксирует generation автоматически; не запускай index build перед каждым вопросом. После явно запрошенного rebuild снова вызови connect. Если MCP отключён, сообщи об этом; shell fallback используй только в установленном CLI-режиме по session.json и не обходи запросы разрешений клиента.

В CLI-режиме перед первым обращением к коду прочитай `.gigacode/seai/session.json`, выполни указанным там seai_bin команды `--data DATA doctor` и `--data DATA project status`, сверь root с project_root. Затем используй seai-connect/research/plan/change/review по задаче. Известные из установки пути не запрашивай заново.

Не используй прямое чтение, обычный поиск, IDE tools или редактирование исходников вместо SEAI. Если подключение или операция недоступны, сообщи об этом и не обходи инструмент. Для другого репозитория нужно отдельное явное подключение, а не чтение соседнего каталога.

Постоянные подробные правила: @.gigacode/seai/POLICY.md

Skills находятся в `.gigacode/skills/seai-*` (CLI layout). Управляющие файлы можно читать напрямую. Само наличие этого файла не является техническим sandbox.
